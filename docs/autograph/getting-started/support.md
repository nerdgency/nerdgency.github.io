# Getting help

For help with Autograph, email [support@triplenerdscore.net](mailto:support@triplenerdscore.net).

## Before you write

1. **Check [Troubleshooting](./troubleshooting.md),** including the [known limitations](./troubleshooting.md#known-limitations).
2. **Update** to the latest Autograph 1.x release.

## What to include

1. **Versions:** Autograph, ExpressionEngine and PHP. Autograph's version is on the **Add-Ons** screen.
2. **Where it happens:** a Channel Form, the publish form, or a template.
3. **What you did,** what you expected, and what happened instead.
4. **The template,** if the problem is on the front end, with the `{exp:channel:form}` or `{exp:channel:entries}` tag as written.
5. **Anything in the browser's console,** and whether `/themes/user/autograph/autograph.js` loads.

Signatures are personal data. Don't send real ones; sign a test entry instead.

## Reporting a security vulnerability

If you think you've found a security problem in Autograph, email [security@nerdgency.ca](mailto:security@nerdgency.ca) rather than describing it anywhere public, and include the steps to reproduce it and the versions you tested.
