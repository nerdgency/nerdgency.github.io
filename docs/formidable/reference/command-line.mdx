# Command line

## Introduction

Formidable adds these commands to ExpressionEngine's command line. Run them from the site's root:

```bash
php system/ee/eecli.php formidable:forms
```

## From the control panel

Every command can also run from [Utilities](/docs/formidable/control-panel/utilities), with a plain-English name and its options as form fields. It runs the same code and prints the same report, so a job tried in the browser can move to cron unchanged.

## Running the workflow queue

With [Formidable's workflow queue](/docs/formidable/automation/workflow-log#the-workflow-queue) turned on, add a cron job that runs the worker every minute. Overlapping runs are safe: each queued run is reserved before it is sent. When BoldMinded's Queue add-on is installed, workflows go to Queue instead, and its `queue:work` is the worker to schedule.

```bash title="crontab"
* * * * * cd /path/to/site && php system/ee/eecli.php formidable:workflows:work >> /dev/null 2>&1
```

## In a deploy script

```bash title="deploy.sh"
# After the add-on files are in place and the update has run:
php system/ee/eecli.php formidable:sync-fieldtypes --dry-run
php system/ee/eecli.php formidable:theme:classes --group=forms_tailwind
npm run build   # your site's own CSS build, which now sees every class
```
