# Installation & Updates

## Requirements

Formidable requires the following to properly install and run:

- ExpressionEngine 7.x
- PHP 8.2 (minimum)
- MySQL 5.6 or newer

## Installation Instructions

- **From the system folder,** copy the `formidable` folder to your ExpressionEngine addons directory: `/system/user/addons/`.
- **From the themes folder,** copy the `formidable` folder to your ExpressionEngine themes directory: `/themes/user/`.
- **From the Add-Ons page** in the ExpressionEngine control panel, find Formidable and click the install button.
