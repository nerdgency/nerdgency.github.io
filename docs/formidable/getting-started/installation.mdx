# Installation

Formidable installs like any other ExpressionEngine add-on: copy two folders onto your site, then choose **Install** in the control panel.

## Requirements

| | |
| --- | --- |
| **ExpressionEngine** | 7.5 or later |
| **PHP** | 8.2 or later. The installer refuses to install or update on anything older, and tells you which version it found. |
| **Database** | Whatever your version of ExpressionEngine requires. Formidable creates its own tables. |

## Getting Formidable

Formidable is sold and downloaded through the ExpressionEngine add-on store: **[Formidable on expressionengine.com](https://expressionengine.com/add-ons/formidable)**, $85. After you buy it, the store gives you the release zip, and updates are downloaded from the same place.

## Installing Formidable

The release zip mirrors the root of an ExpressionEngine site, so each folder goes to the same place on yours:

```text title="Formidable-v1.1.0.zip"
system/user/addons/formidable/   →  your-site/system/user/addons/formidable/
themes/user/formidable/          →  your-site/themes/user/formidable/
```

<Steps>
  <Step title="Copy the add-on">
    Copy `system/user/addons/formidable` into your site's `system/user/addons/` folder.
  </Step>
  <Step title="Copy the front-end assets">
    Copy `themes/user/formidable` into your site's public `themes/user/` folder. It holds `formidable.js`, which runs conditions, pages and repeating sections in the browser, and the signature pad's script and styles.
  </Step>
  <Step title="Install from the control panel">
    Open **Add-Ons**, find **Formidable** and choose **Install**. The installer creates Formidable's tables, its fieldtypes, validation rules and attributes, and the **Formidable Form** channel fieldtype.
  </Step>
  <Step title="Open Formidable">
    Formidable now appears under **Add-Ons** and opens on its [dashboard](/docs/formidable/control-panel/dashboard), which offers to **set Formidable up**: a few short steps through how forms look, spam protection, email, what's kept and background work. See [the setup wizard](/docs/formidable/control-panel/configuration#the-setup-wizard). Then you're ready to build [your first form](./your-first-form.mdx).
  </Step>
</Steps>

:::tip Giving your team access
Super Admins can do everything straight away. To let other roles build forms, read submissions or manage connections, grant them Formidable's permissions on **Formidable › Permissions**. See [Permissions](/docs/formidable/control-panel/permissions).
:::

## Updating

<Steps>
  <Step title="Replace both folders">
    Copy the new `system/user/addons/formidable` and `themes/user/formidable` over the old ones. Replace the folders rather than merging them, so no file the new release removed is left behind.
  </Step>
  <Step title="Run the update">
    ExpressionEngine notices the new version on the **Add-Ons** screen and offers **Update**. The update runs any new database migrations and adds any new fieldtypes.
  </Step>
  <Step title="Check Configuration">
    **Formidable › Configuration** opens with [health checks](/docs/formidable/control-panel/configuration#health-checks). If a table or a fieldtype is missing, it says so, with the command or button that fixes it.
  </Step>
</Steps>

Read the [upgrade guide](/docs/formidable/prologue/upgrade-guide) before updating across a release with breaking changes.

## Optional configuration

Formidable works with no configuration at all. A handful of behaviours can be tuned from your site's `config.php`. For example, to let a form's `return=` send visitors to another host:

```php title="system/user/config/config.php"
$config['formidable_return_hosts'] = ['checkout.example.com'];
```

Every key is listed under [Configuration](/docs/formidable/reference/configuration).

## Uninstalling

Choose **Uninstall** for Formidable on the **Add-Ons** screen.

:::danger This deletes your forms and submissions
Uninstalling removes Formidable's tables, including every form and submission. Export anything you want to keep first, from each form's **Submissions** screen.
:::
