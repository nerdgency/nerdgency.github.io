# Extension hooks

Formidable calls these ExpressionEngine extension hooks. Register for them from your own add-on's extension in the usual way.

## `formidable_submission_complete`

Called after a submission has passed validation and been stored (unless the form does not store submissions), and **before** workflows run. Also called when a visitor edits a submission through `submission_handle=`.

```php title="system/user/addons/my_addon/ext.my_addon.php"
public function formidable_submission_complete($form, $submission, array $values): void
{
    // $form        the Formidable Form model
    // $submission  the stored Submission model, or null when the form does not store submissions
    // $values      the submitted answers, keyed by field handle
}
```

## `formidable_spam_caught`

Called when a submission is caught by the honeypot, the JavaScript honeypot or the rate limit, after the form's spam count is increased. It is not called for failed CAPTCHAs or duplicate submissions.

```php title="system/user/addons/my_addon/ext.my_addon.php"
public function formidable_spam_caught($form, string $caughtBy): void
{
    // $caughtBy is 'honeypot', 'js_honeypot' or 'rate_limit'
}
```

Formidable keeps no log of caught spam and stores no IP addresses for it. This hook is how a site keeps its own record.
