# Command line

Formidable adds these commands to ExpressionEngine's command line. Run them from the site's root:

```bash
php system/ee/eecli.php formidable:forms
```

## In a deploy script

```bash title="deploy.sh"
# After the add-on files are in place and the update has run:
php system/ee/eecli.php formidable:sync-fieldtypes --dry-run
php system/ee/eecli.php formidable:theme:classes --group=forms_tailwind
npm run build   # your site's own CSS build, which now sees every class
```
