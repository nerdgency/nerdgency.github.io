# Configuration (config.php)

Most settings live on **Formidable › Configuration** and on each form. See [Settings and inheritance](/docs/formidable/core-concepts/settings-and-inheritance). A few behaviours are set in the site's `system/user/config/config.php` instead, with keys prefixed `formidable_`. They survive add-on updates. Do not edit the add-on's own `config/config.php`, which is replaced by every update.

```php title="system/user/config/config.php"
$config['formidable_rate_limit'] = 20;
$config['formidable_return_hosts'] = ['checkout.example.com'];
```

The spam settings `formidable_rate_limit`, `formidable_rate_window` and `formidable_duplicate_window` can also be set on **Configuration › Spam**. When both are set, `config.php` wins.
