# `{exp:formidable:api_url}`

Prints the URL of a [JSON API](/docs/formidable/developer/json-api) endpoint. The API is one ExpressionEngine action whose id differs between installs, so templates should never hard-code it.

<VersionNotice />

## Parameters

<Param tag="api_url" name="form_handle" example='form_handle="contact_us"'>

A form's endpoint: `forms/{form_handle}`.

</Param>

<Param tag="api_url" name="submissions" values={<code>yes</code>}>

With `form_handle=`, the form's submissions endpoint instead: `forms/{form_handle}/submissions`.

</Param>

<Param tag="api_url" name="endpoint" example='endpoint="forms"'>

Any endpoint, written out. Used when `form_handle=` is not given.

</Param>

<CapturedExample name="api-url" title="Endpoint URLs for a script" />

The URL alone does not grant anything. Whether a request to it succeeds depends on who makes it. See [Who may call it](/docs/formidable/developer/json-api#who-may-call-it).
